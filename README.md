# Hariprasath V S — Portfolio

A responsive beige-themed portfolio website.

## Files
- index.html — portfolio content
- style.css — design and responsive layout
- script.js — scroll reveal and smooth navigation

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize
Replace the `HVS` placeholder in the hero card with a profile photo if desired.
Update project descriptions, links, achievements, and contact details in `index.html`.
